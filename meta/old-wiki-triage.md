# Old wiki triage list

The old Confluence wiki had 81 pages. This list says what to do with each one.
Use it at the lab meeting: for each page under **Needs a decision**, pick **keep** (someone
rewrites it as a short new page and owns it), **link** (an official source already covers it),
or **drop**. Write the decision and, for *keep*, the new owner.

The old pages, converted to Markdown, are on the lab server in `Lab WIki/_old-wiki-markdown/`
(one file per page). The original export is next to it. Neither is on GitHub.

*Dates are the old "last modified" dates. Many pages show April 2022 because of a bulk move,
so that date says little about when the content was last checked.*
